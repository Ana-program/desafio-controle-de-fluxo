# 🚦 Desafio Controle de Fluxo

Este é um projeto em Java que tem como objetivo simular o controle de fluxo de um contador. O programa recebe dois parâmetros do usuário e imprime todos os números entre o primeiro e o segundo, desde que o primeiro seja menor que o segundo. Caso contrário, o programa lança uma exceção personalizada.


## 📌 Funcionalidades

Solicita dois parâmetros inteiros: parametro1 e parametro2.

Caso parametro1 seja maior ou igual a parametro2, uma exceção personalizada é lançada.

Se os parâmetros forem válidos, o programa imprime todos os números entre parametro1 e parametro2 - 1.


## 🛠 Tecnologias Utilizadas
- Java
